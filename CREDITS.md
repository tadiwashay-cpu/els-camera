# Credits

## Made for this game
- **Fighter rig and all 36 animations**: authored for Block Duelist 3D in
  Blender with `tools/blender/` scripts.
- **Fighters, weapons, arena**: built from boxes in code (`src/`).
- **Sound effects**: synthesised at startup by `src/autoload/audio.gd`.
- **Icon and splash**: rendered from a block fighter by `tools/capture/icon_render.tscn`.

## Engine and tools
- **Godot Engine** 4.7.2, MIT licence. https://godotengine.org
- **Jolt Physics** (built into Godot), MIT licence.
- **GUT** (Godot Unit Test) 9.7.1 by Butch Wesley, MIT licence,
  `addons/gut/` (tests only, not shipped in the APK).
- **Blender** 5.3 (GPL) is used as a tool to build the animations; no Blender
  code ships with the game.
